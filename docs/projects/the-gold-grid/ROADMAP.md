# The Gold Grid: roadmap

Phases run in order. Each has a check that must pass before the next one starts.

## Phase 0: prototype (done)

- [x] Factoring handout and adaptive quiz, to find the teaching approach.
- [x] Times tables trainer, version 1: 13 levels, grid, today's ten, streak, timed round, parent corner.
- [x] Version 2: division.
- [x] eStage project created (80750) and connected.

## Phase 1: tier 1 on eStage (next)

- [ ] Read the eStage project's rules and structure.
- [ ] Port the trainer into the project as the home page, with Times and Divide.
- [ ] Check it in the eStage preview at phone and desktop width, in light and dark.
- [ ] Owner reviews the preview.
- [ ] Add the pages a public site needs: a short "for parents" page, privacy, and contact.
- [ ] Register the domain and connect it.
- [ ] Publish.

**Check before phase 2:** the trainer works on the published site on a phone and a laptop, and progress survives closing and reopening the browser.

## Phase 2: try it with families

- [ ] Give it to three to five children. Watch where they get stuck or bored.
- [ ] Fix what they find.
- [ ] Widen to 10 to 20 families.
- [ ] Turn on eStage Insights to count visits and returns.

**Check before phase 3:** children are still using it in week three. If they are not, fix that before building anything paid.

## Phase 3: tier 2, the memory layer

- [ ] Parent sign-on. Child profiles under it, opened with a PIN and no email.
- [ ] Progress saved to the eStage cloud database, visible only to that family.
- [ ] Parent view: the grid over time, accuracy per table, slips shrinking or growing, and one plain sentence on top.
- [ ] Weekly email to the parent.
- [ ] Product and checkout: per family, monthly and annual, with a free trial.
- [ ] Privacy review for children's data before launch.

**Check before phase 4:** parents open the weekly report, and some of them pay.

## Phase 4: more skills

Each builds on the one before:

- [ ] Multiplying larger numbers by breaking them apart.
- [ ] Fractions.
- [ ] Negative numbers.
- [ ] Simple equations.
- [ ] Factoring (already prototyped).

## Phase 5: tier 3

- [ ] Practice from a photo of homework, with a monthly limit.
- [ ] Explain it back, and a tutor that asks leading questions.
- [ ] Price set from the measured cost of each use.

## Ideas not yet scheduled

- A map or path showing the levels as stops.
- A puzzle wrapper where right answers reveal a picture.
- "Challenge your parent" weekly set.
- "How sure are you?" confidence tap.
- "Find the mistake" questions.
- A weekly printed page built from the child's own slips.
- Requiring separate days, not just separate questions, before a fact turns gold.
